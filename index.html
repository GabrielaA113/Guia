Aprenda os comandos essenciais do Git de forma simples e prática!

Comandos Essenciais

>_git init

Inicializa um novo repositório Git em um diretório.

>_git add .

Adiciona os arquivos modificados ao índice, preparando-os para o próximo commit.

>_git commit -m

Registra as alterações do projeto em um novo commit com uma mensagem.

>_git push

Envia as alterações do repositório local para o repositório remoto.

>_git pull

Baixa e integra as alterações do repositório remoto no repositório local.

>_git fetch

Busca alterações do remoto sem integrá-las automaticamente ao seu branch.

>_git branch

Cria, lista e gerencia branches dentro do seu repositório.

>_git clone

Cria uma cópia local de um repositório remoto.

Dica:

push envia suas alterações para o repositório remoto.

pull traz para o computador as alterações que estão no remoto.
