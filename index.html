Guia de Git para Iniciantes

Comandos Essenciais

git init

O comando git init é utilizado para inicializar um novo repositório Git em um diretório.

git add .

O comando git add . é utilizado para adicionar todos os arquivos modificados e novos ao índice do Git, preparando-os para o próximo commit.

git commit -m "[Mensagem de Commit]"

O comando git commit -m "mensagem" é utilizado para criar um novo commit no repositório Git, registrando as alterações feitas nos arquivos adicionados ao índice, juntamente com uma mensagem descritiva.

git push -u origin main

O comando git push -u origin main é utilizado para enviar as alterações locais para o repositório remoto, configurando o upstream.

git pull

O comando git pull é utilizado para atualizar o repositório local com as alterações do repositório remoto, mesclando as mudanças.

git fetch

O comando git fetch é utilizado para buscar as alterações do repositório remoto sem mesclá-las automaticamente, permitindo revisar as mudanças antes de integrá-las ao repositório local.

git branch

O comando git branch é utilizado para criar, listar, renomear ou excluir ramos (branches) no repositório Git.

git clone [Link do Repositório]

O comando git clone é utilizado para criar uma cópia local de um repositório Git existente.

Dica: ['push'] é o comando para enviar alterações para o repositório remoto. E ['pull'] é o comando para atualizar o repositório local com as alterações do repositório remoto.
